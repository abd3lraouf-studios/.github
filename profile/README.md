# abd3lraouf Studios

We build native Apple platform apps. Our work lives in public repos under this
org.

## Projects

- **[PrayerTimes](https://github.com/abd3lraouf-studios/PrayerTimes)** — prayer
  times in your Mac's menu bar. Available on the Mac App Store and via
  Homebrew.

## Infrastructure

- [Shared Homebrew tap](https://github.com/abd3lraouf-studios/homebrew-tap) — install any of our apps with `brew install --cask abd3lraouf-studios/tap/<app>`
